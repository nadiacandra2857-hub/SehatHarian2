1. Ringkasan Produk
SehatHarian adalah aplikasi desktop untuk membantu individu membangun kebiasaan hidup sehat melalui tantangan harian yang realistis. Fitur meliputi rekomendasi aktivitas, pelacakan tidur, aktivitas, hidrasi dan kebiasaan makan, pengingat tidur, grafik konsistensi mingguan, serta evaluasi berdasarkan data pengguna.
PRD ini menjadi acuan desain, implementasi, integrasi database, dan pengujian. Stack final: Java 26, JavaFX, FXML, JavaFX CSS, Gradle, MySQL, JDBC, MySQL Connector/J, JavaFX Charts, dan JUnit.
2. Latar Belakang
Proposal menjelaskan bahwa pengetahuan hidup sehat belum selalu menjadi kebiasaan konsisten. Keterbatasan waktu, motivasi, dan rutinitas dapat menghambat aktivitas fisik serta pola makan sehat. SehatHarian membantu pengguna memulai dari langkah kecil, mencatat kebiasaan, dan melihat perkembangan dari waktu ke waktu.
3. Tujuan Produk
Mendorong kebiasaan hidup sehat secara bertahap dan konsisten.
Menyediakan tantangan realistis berdasarkan konteks pengguna.
Merekomendasikan aktivitas, menu, dan workout berdasarkan waktu luang, kesibukan, dan golongan usia.
Memusatkan catatan tidur, aktivitas, hidrasi, dan kebiasaan makan.
Menyediakan pengingat tidur, grafik mingguan, dan evaluasi berbasis data aktual.

10. Tech Stack
Pembagian berikut berdasarkan tanggung jawab aplikasi desktop. Tidak ada server backend terpisah pada versi ini; backend berarti lapisan internal service/repository yang berjalan di aplikasi.

JavaFX

FXML

JavaFX CSS
Styling warna, tipografi, jarak, status, dan konsistensi visual.

10.2 Backend Internal — Logika dan Akses Data
Teknologi
Peran
Java 26
Model, validasi, service, aturan bisnis, dan repository.
JDBC
API Java untuk menjalankan query dan transaksi database.
MySQL Connector/J
Driver JDBC untuk koneksi Java ke MySQL.
MySQL
Penyimpanan persisten profil, katalog, catatan, riwayat, dan evaluasi.
Gradle
Build tool untuk dependensi, kompilasi, menjalankan aplikasi, dan tugas pengujian.
JUnit
Pengujian aturan tidur, filter rekomendasi, evaluasi, dan logika service.
10.3 Struktur tanggung jawab
View: FXML dan JavaFX CSS.
Controller: menerima aksi pengguna dan menghubungkan view dengan service; tidak menaruh query SQL.
Service: validasi, aturan bisnis, perhitungan tidur, rekomendasi, dan evaluasi.
Repository/DAO: query SQL melalui JDBC dan PreparedStatement.
Model: representasi data seperti Pengguna, Tantangan, JadwalTidur, Aktivitas, Hidrasi, dan EvaluasiMingguan.
Database: MySQL.
Gradle mendukung build seluruh aplikasi, bukan hanya backend. JUnit digunakan untuk pengujian, bukan sebagai komponen runtime UI.
11. Kebutuhan Nonfungsional
Antarmuka mudah dipahami dan teks nyaman dibaca oleh dewasa maupun lansia.
Data harus konsisten setelah disimpan dan dibaca kembali.
Perhitungan waktu tidur dan rentang mingguan harus akurat.
Gunakan PreparedStatement; hindari kredensial database di log atau repository publik.
Operasi database tidak boleh membekukan JavaFX Application Thread.
Tampilkan loading, empty state, keberhasilan, dan kesalahan secara jelas.
Kontras warna memadai; status tidak bergantung hanya pada warna.
12. Pedoman UI/UX
Tampilkan hierarki informasi yang jelas dan navigasi yang konsisten.
Utamakan tantangan hari ini, aksi pencatatan, dan ringkasan yang berguna.
Jangan menampilkan angka atau grafik palsu seolah data pengguna.
Saat data kosong, tampilkan empty state yang informatif.
Filter harus benar-benar mengubah hasil dan menampilkan pilihan aktif.
Tombol harus memiliki aksi nyata; sukses hanya ditampilkan setelah operasi berhasil.
Gunakan ukuran teks dan area klik yang nyaman.

14. Risiko dan Ketergantungan
MySQL harus berjalan dan kredensial/koneksi dikonfigurasi benar.
Karena aplikasi desktop terhubung langsung ke MySQL, distribusi ke banyak komputer membutuhkan perhatian pada jaringan, hak akses, dan perlindungan kredensial.
Scheduler di dalam aplikasi tidak menjamin pengingat ketika proses aplikasi benar-benar ditutup; integrasi OS mungkin diperlukan.
Grafik dan evaluasi bergantung pada kelengkapan catatan.
Katalog dan aturan rekomendasi harus jelas agar hasil relevan.
